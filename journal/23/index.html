第二十三章：程序员式浪漫

自从那天小璇发烧迷迷糊糊叫了我名字，我俩的关系……不能说“正式”，但绝对是从“TCP 三次握手”变成了“长连接”。

连小马哥都能看出来。

每天我在工位那边一笑，他就从隔壁探个头：“哟，这是女朋友发消息了？”

我说：“不是……就是 UI 小璇——”

他立刻打断：“哦，那就是‘准’女朋友。”

我装作没听见，但心里其实比 MySQL 主从同步还稳。

就在这段暧昧又甜蜜的日子里，我突然想起来一个关键事件——

小璇生日快到了。

我怎么知道她生日的？山人自有妙计

说实话，我不是什么生活观察大师。

但我知道一件事：

想追 UI 妹妹，必须用 UI 妹妹懂得的方式浪漫。

她喜欢细节，那我必须抓住细节。

她生日是哪天？

我灵光一闪，开始了我的“社工渗透行动”。

我悄悄联系了原来第一家公司跟她最好的女同事。

刚开口我就尴尬：“姐，我能问你个事吗，就是……小璇她……那个……生日是……”

她秒回：“你追她啊？”

我：？？？

“啊……没有，就是……关心同事……”

“行了别装了，你上次见到她都高兴得跟抢到年终奖似的。”

然后，对方发来一句：

“她生日5月20号，不用谢我，有结果请我喝奶茶。”

我差点感动得当场发个 200 块的红包过去。

但为了显得自然，我得假装自己“无师自通”。
毕竟我们程序员的自尊是靠一点点体面撑起来的。

我决定做一件“程序员式浪漫”

别人给女朋友过生日：鲜花、蜡烛、蛋糕、礼物。

我给 UI 女朋友：
写一段代码祝她生日快乐。

为什么？

因为这世界上没有什么比写代码更能代表程序员的真心（和拙劣的浪漫）了。

我在 VS Code 里敲下：

public class BirthdayWish {
    public static void main(String[] args) {
        String name = "XiaoXuan";
        for(int i = 0; i < name.length(); i++) {
            System.out.print(name.charAt(i));
        }
        System.out.println(", Happy Birthday!");
        System.out.println("愿你的生活像UI一样美好，像bug一样让我上头。");
    }
}

还加了点彩蛋：

boolean likeYou = true;

while(likeYou){
    System.out.println("祝你生日快乐！");
    break;
}

我准备把代码打印在贺卡上，再送她。

但事情没那么简单——我想让她惊喜，而不是看到就知道我做了。

庆祝方案必须升级。

于是我找到了最合适的两个男人——

小马哥 & 伟源：离谱策划组上线

我刚把想法说完，小马哥立刻举手：

“整一个！但你这太朴素了，不够炸裂！”

伟源点头：“对！我们程序员搞浪漫，必须把脑子烧一点。”

然后他们开始现场头脑风暴。

小马哥提议：“这样！我们提前在公司放一个假 bug。”

我一愣：“你是让我被开除吗？”

“你听我说完！这个假 bug 的控制台打印——‘Happy Birthday to XiaoXuan’！”

我：“……你这是要我送命。”

伟源补刀：“那可以做个小型前端页面，让她点开就看到你写的生日祝福代码！”

我眼睛亮了：“这个可以！”

三个人当场开会，效率堪比产品经理驱赶开发写需求。

生日当天：UI 小姐姐被吓到（但是被甜到的那种）

那天我装作若无其事地去上班。

小璇一来，坐下没五分钟，我悄悄发她一个链接。

她疑惑地看了我一眼：“啥？你让人点奇怪链接？不会被抓吧？”

我一本正经：“放心，HTTPS 的。”

她点开。

屏幕亮起一个我们三人熬到凌晨做的小页面——

左半边是我写的代码生日祝福动画打印出来，
右半边是我写给她的一句温柔得不像程序员的话：

“希望我以后的每一年生日，都能在你身边说一句：生日快乐，小璇。”

她看完不说话。

我心里一紧：完了完了，是不是太肉麻了？是不是用 Java 写祝福太土？

结果小璇突然抬头，眼睛亮亮的：

“你……你怎么知道我生日的？”

我咳嗽一声：“山人自有妙计。”

她盯着我：“你说。”

我：“嗯……我自己推断的。”

她眯眼：“你再说。”

我立刻认怂：“我问的你以前那位女同事。”

她噗嗤笑出来：“你这个人……偷偷摸摸的。”

我心虚又得意：“这叫……精准需求分析。”

她捂着嘴笑得肩膀都抖了：“你们程序员……真的好奇怪。”

“但我喜欢这种奇怪。”

我心脏被她这句短短的告白，敲得像有人在按回车键连击。

小惊喜的最后一环（小马哥的“50分浪漫”）

午休的时候，小马哥突然假装路过，塞给小璇一个小袋子：

“我们部门的小礼物，不贵，开心就好。”

小璇打开。

里面是一只公仔，戴着小程序员眼镜，还背着个小电脑。

她笑得弯起眼角：“这是你挑的吗？”

我摇头：“不是。”

她看向小马哥。

小马哥摆手：“别看我，是他挑的，我只是负责递。”

她又笑着看我：“你真是……一点一点地偷偷对人好。”

我挠头：“那你喜欢吗？”

她轻轻点头：“喜欢。”

那天，下班的时候，她突然抓住我的袖子。

我愣住。

她没看我，只轻轻说了一句：

“以后……我的生日能不能都让你过？”

我心跳直接重启：

“当然可以。”

她抬头看我，眼睛亮得像春天：

“那……我们是不是算正式……在一起了？”

那一刻，我觉得自己像把一行行代码 push 到了人生最重要的仓库里——
永久保存，永不回滚。
