我回武汉那天，我妈问的第一句话是：“中午吃了没有？”

我说吃了，在车上吃的。

她看了一眼我的箱子，又看了一眼我的脸，像检查一个快递有没有在运输途中发生破损。

“车上那个不算。我炖了汤。”

于是，2021 年四月初，我还没到新公司报到，先在家接受了一次高强度补充营养。

汤里有排骨，桌上有鱼，还有一盘我已经忘了上一次什么时候吃过的藕带。我妈说随便做了点，让我不要客气。

回自己家还要不要客气，我不知道。我只知道，她那个“随便”的资源消耗，比我们以前正式环境的一次全量更新都大。

我爸坐在对面，夹了两筷子菜，问：“这回工作定了吧？”

“定了。合同和待遇都谈过了，下周报到。”

“那就好。”

他说完，又问公司在哪一片。

我把地址给他看。他眯着眼研究半天，最后得出一个结论：离家挺远。

这句话让我刚喝进去的汤稍微停了一下。

我从深圳回了武汉，距离并没有从生活里消失，只是换了一种算法。

春节没回来，这时候回来，我妈多少有些意见。

不过她的意见一般不直接表达，而是藏在夹菜的动作里。

“过年让你回来，你说不折腾。”

“那时候还在找工作。”

“工作也不能一天二十四小时找。”

我没接话。

她说得对。春节那几天，招聘软件安静得像一个已经停止维护的群。可我当时就是觉得，人在深圳，机会要是真来了，至少能立刻去。

哪怕那个机会，迟迟没来。

年底整个项目被停掉时，我们谁也没有留下。小马哥的客户排期，伟源还没收尾的测试记录，小璇电脑里的设计稿，还有我那堆自认为已经整理得挺清楚的后续计划，一起失去了下一个版本。

公司还在，项目没了。

大家交接的时候，甚至找不出一个以后真要接手的人。

我当时给家里打电话，说今年春节先不回去，年底也没什么公司招人，正好出去走走，回来再找。

那趟旅行我和小璇确实去了。没走很远，住得也普通，临出发前还把接下来几个月的房租留在了另一张卡里。

第一天睡醒，我习惯性伸手摸手机，想看看群里有没有人艾特。

小璇把手机从我手里抽走，说：“今天你最大的任务，是决定早饭吃什么。”

我用了十分钟，最后还是让她决定。

原来脱离工作以后，我的决策能力并没有想象中那么强。

回来之后，我们才正式开始投简历。她没用多久就找到新的设计工作，我替她检查入职材料，给她煮了碗面，嘴上还说以后要靠小璇老师罩着。

那时候我是真替她高兴，也真觉得自己再等一两周，应该差不多。

后来，一两周变成一个月，又变成下一个月。

有公司跟我聊完项目，第二轮全问八股；有公司技术聊得不错，到谈待遇就再没回音；还有一次我已经开始查通勤路线，对方才告诉我岗位暂缓。

我知道自己做过什么，也能讲清楚怎么做的。可在招聘软件上，我和几百个写着 Java 的人挤在同一个入口，谁都显得差不多。

到后来，“再等等”这三个字，我自己都不爱听。

老清就是那时候给我打的电话。

他说他们公司缺一个能接业务的 Java，让我把简历发过去看看。没有拍胸脯保证，只说岗位是真的，负责人他熟，能帮忙递到人手里。

远程聊了两轮，又谈了一次具体工作，我才把回武汉这件事告诉家里。

工资比以前少了一截，但不是一个只能硬着头皮接的数字。职责明确，到岗时间明确，连前三个月要接哪一块都说了。

我需要的，恰好就是这份明确。

下午，我把行李推回原来的房间。

书桌还在，上面多了一盆绿萝和一个装针线的饼干盒。我的位置被生活临时征用了几年，现在重新上线，需要先清理一下缓存。

我妈进来给我换床单，说：“回来就好，晚上别熬了。”

我说好。

她接着问：“明天能不能陪我去拿个东西？”

“几点？”

“上午。顺便看看你舅家那个电脑。”

我还没回答，我爸从客厅补了一句：“打印机也连不上，他上回就问了。”

我站在屋里，突然发现，家里对程序员的理解一直非常稳定。

工作时是不知道在忙什么，回家后是什么都应该会修。

“明天上午我要补入职资料，还要看一下他们发的业务介绍。”

我妈愣了一下：“这不是还没上班吗？”

“就是先熟悉一下，不然进去两眼一抹黑。”

她有点失望，伸手把床单另一角抻平了。

我看着她，后半句本来已经到了嘴边——你们怎么总觉得我坐电脑前就有空。

可我又把它咽了回去。

她确实不知道我在做什么。以前隔着电话，我只说忙；现在人回来了，还是一个忙字，把她挡在门外，她也没地方了解。

我把手机上的安排给她看：“上午弄材料，下午陪你去。电脑能修就修，不能修我给他找个店，不能承诺包好。”

我爸在客厅笑了：“你还先讲条件。”

“售后范围要说清楚。”

我妈也笑了，把新枕套往我怀里一塞，让我自己装。

原来在家里设个边界，也不一定非得开一场需求评审会。

晚上，小璇给我发消息，问到家有没有吃上饭。

我拍了张桌上的剩菜给她。

她回：“你妈是不是觉得深圳不给你饭吃？”

“从这个配置判断，应该还怀疑我最近参与了荒野求生。”

她发来一个笑哭的表情，过了一会儿，视频打过来。

镜头里的背景已经不是我们原来那间屋子。

她搬到了更适合新工作通勤的住处。搬家的时候我还在，帮她装了衣架，把重一点的箱子推到墙边。可隔着屏幕再看，那面墙突然有点陌生。

“你东西收好了？”她问。

“差不多。发现我书桌已经转型成为综合储物中心。”

她笑着让我转一下镜头，看看我以前的房间。

我给她看书柜，看早就不走的闹钟，看桌角一道不知道哪年留下的划痕。她说原来你的键盘以前放这里，我说是，只不过那时候主要用来打游戏，没有承担过这么复杂的家庭经济责任。

聊了一会儿，她突然安静下来。

“今天我妈又问，我还去不去武汉。”

我停下了手里的动作。

“你怎么说？”

“说先不去。工作刚定下来，也还没跟他们谈通。”

她抿了一下嘴唇，又说：“他们就是觉得太远了，真有点事也照应不到。我说你在这边，有熟人，他们还是担心。”

这段话在离开深圳之前，我们已经聊过好几次。

她想过跟我走，也认真问过武汉的设计岗位。父母的反对没有因为一份招聘截图就消失。我这边的工作又不能一直等下去。

最后我们坐在地板上，旁边是没封口的纸箱，决定先这样过一阵。

说这句话时，我们还在同一间屋子里。

现在才真正开始知道“这样”是什么样。

我说：“慢慢谈吧，别一打电话就吵。我这边先把工作做起来。”

“嗯。”

“五一看看怎么安排，或者你生日那时候，我过去。”

她点点头，让我别刚入职就乱请假，先看看工作情况。

我妈在门外喊我吃水果，我下意识把手机往旁边挪了一下。小璇看见我的动作，笑着说去吧，别让阿姨觉得你回来还要开会。

挂掉视频后，我把她刚才问过的旧闹钟翻过来，找了一节电池装上。

秒针动了两下，又停住。

我研究了一会儿，放弃了。一个写了几年代码的人，回家第一天没能修好自己桌上的闹钟，倒也很符合我们家对我的实际使用反馈。

接下来两天，我开始适应家里的时间。

早上六点多，我妈已经在厨房。锅盖碰到灶台，水龙头打开，塑料袋哗啦一响，我闭着眼都知道她在做什么。

我以前以为回来可以睡个懒觉，后来发现，家里虽然没有打卡机，但有一套覆盖范围更广的提醒系统。

“早饭再不吃就凉了。”

这句话能穿过两扇门。

我起床吃饭，把要做的事情说了一遍，去电脑前补齐材料，下午按约定陪她出门，又去了趟舅家。

电脑开机启动的东西太多，几款软件互相弹窗，每一个都热情地声称自己正在保护电脑。

打印机是驱动的问题。我核了设备型号，找到能确认来源的驱动，装好以后先打一页测试，再让他们自己操作一遍。

我舅盯着那张纸从机器里出来，高兴得像我们刚刚解决了整个行业的难题。

“专业的就是不一样。”

我说下次别看见软件推荐就全点同意，这几位保护电脑的同志，已经快把正常使用的人保护在外面了。

大家都笑了。

笑完，他问我怎么突然回来了，是不是深圳现在不好找工作。

我妈在旁边接话，说武汉也不错，离家近，朋友公司正好有机会。

她说得很快，像怕我还没想好怎么回答。

我坐在电脑前，手指停在鼠标上，忽然意识到她虽然嘴上总念叨回家好，也知道我回来并不是一路轻松地挑出来的。

“是没找到。”我说，“前面那个项目停了，找了几个月没合适的结果，这边有明确岗位，就回来了。”

说完以后，屋里没有发生我想象中的尴尬。

我舅只是点点头，说有活干就好，朋友能帮着介绍，也是平时处得好。

我妈看看我，没有再抢着往下解释。

回家的路上，她问我别人再问起来，怎么说比较好。

我说就按刚才那个说。

“你别觉得丢人。”她说。

“我没觉得。”

这句回答出来得太快，我自己先知道没那么完全。

她没拆穿，只说你爸前些天还在看这边招人的信息，看得也看不懂，一会儿问 Java 是什么，一会儿又问那些年限能不能算别的工作。

我停了一下。

“他怎么没跟我说？”

“怕瞎帮忙给你添乱。”

我想起这几个月打回家的电话，父亲总是最后在旁边说一句慢慢找，别急。我以为他真的一点不急。

到了家，我爸正在看手机，见我们回来，先问打印机好了没有。

我说好了，接着坐到他旁边，主动把新工作的业务讲了一遍。

不用代码，也不说那些他听不懂的框架，就说一家店要多少货、仓库发了多少、两边账怎么对上，我们做的是帮人把这些事记清楚、查明白的系统。

他听完说，这个实在，开店总要用。

我笑了，没急着解释软件生意并没有这么简单。

至少这回，他知道我下周去上班，大概是在做什么。

我回屋拿资料时，看到我妈已经把那个装针线的饼干盒从书桌移走，放回了客厅柜子。

桌面上还空出一块放鼠标的地方。

她没有再问我坐着是不是就有空。

晚饭后，我主动把碗收进厨房。我妈说放着她来，我没放，拧开水洗了。

她站在旁边看了一会儿，忽然问：“在深圳也洗啊？”

我说不然等它自己干净？

她笑了，转身去收桌子。

我这才意识到，离开家这几年，我学会的很多小事，他们都没机会看见。在他们的印象里，我可能还是那个吃完饭就回房间打开电脑的人。

水槽里的碗不多，我洗好放回去，又问抹布在哪儿。她隔着客厅告诉我，我照着找到，把台面擦干。

手机亮起来，老清发来消息。

“周五下午我带你去公司转一圈？跟陈工碰一下，晚上吃烧烤。”

我回了个好，把时间记进日历。

桌上是一碗刚切好的苹果，电脑里是新公司的业务资料。小璇随后发来她明天要穿的两件外套，问我哪件好看。

我放大看了一会儿，认真选了左边那件。

她说：“行，那我穿右边。”

我看着屏幕笑出声。

这个流程至少还和以前一样。
