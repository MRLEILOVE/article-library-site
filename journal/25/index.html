第二十五章：618的夜里只有代码和她的关心不下线

阿雷1,673 字约 5 分钟

6 月初，公司开始集体躁动。

原因只有一个——
618 大促。

虽然我们不是卖手机的，也不是卖电饭煲的，但保洁服务在 618 这几天也得跟着狂欢：

“深度保洁 9.9 起！”
“专业阿姨上门，限时满减！”
“老板血亏，程序员哭泣！”

这类标语在工单系统里跳得比我写的 bug 还频繁。

顺哥严肃宣布：

“这波 618，我要活动专题页上线；首页 Banner 动效必须做；优惠券系统要重构；还有埋点要做。”

我：“……顺哥，你这是让我一个人写一部《红楼梦》啊。”

顺哥拍拍我肩：“放心，你不是一个人。你们后端三个，UI 一个，前端两个，你们是战队。”

我看向 UI 小姐姐。

她眨眨眼：“一起努力吧~”

那一瞬间，我突然觉得——
这 618 再难，我也干了。

加班第一夜：活动专题页写到怀疑人生

我坐在工位，写活动接口写到眼冒金星。
活动规则链路复杂得像个被产品经理随机生成的迷宫。

“满 199 减 20；满 299 减 40；跨店满减叠加券；加购打折；老用户拉新返钱……”

我写一半突然站起来，怀疑人生：

“为啥保洁还能搞成电商玩法？我们这是做卫生还是做巴菲特套利？”

小璇听到了，笑得肩膀抖：

“你是不是快崩溃了？”

我把头埋在桌上：“你来体验一下这个优惠计算逻辑，你立刻原地离职。”

她靠过来，轻轻贴在我耳边说了一句：

“辛苦啦，我给你泡一杯枸杞红枣茶。”

我愣住。

我不是因为体贴愣住……
是因为她泡的那一杯，
里！面！有！红！枣！

我突然感觉到一种来自 UI 岗位的温柔暴击。

第二夜：前端小姐姐被接口坑惨，小璇护着我

凌晨 12 点半。

前端小姐姐红姐喊我：“小雷你这个接口返回格式是不是又改了！”

我看看日志：“啊？不会吧？我没动啊……等等，好像是顺哥刚才说让加一个字段……”

红姐气得要跳起来，准备喷我。

结果小璇从旁边冒出来：

“红姐你别凶他啦！他这两天虽然写 bug 多了一点，但他已经很努力了。”

我：“……虽然你维护我我很感动，但你这句评价也太真实了吧。”

红姐：
“行吧，看在你女朋友替你说话的份上，我饶你一次。”

那一刻我悟了：

恋爱带来的最大 buff，不是快乐，而是……有人替你挡骂。

第三夜：我们在办公室偷偷牵手

凌晨一点半。

办公室灯光昏昏沉沉，大家都累得不行。

我在写优惠券计算逻辑，小璇就在旁边切图、做 banner 动效。

我看了她一眼。

她也刚好抬头。

两个人就这么对视了四五秒。

然后，她轻轻把手伸过来。

我犹豫一秒，也把手放上去。

夜深办公室格外寂静，我们的手就这么轻轻握在一起。

不是激烈的，是很安静很安静的那种。

小璇小声说：

“有你在这里，我好像一点都不累。”

我忍不住心脏抽了一下：

“有你在，我也觉得这活动咋那么甜。”

她被我逗得笑出声：“你这个程序员，怎么越来越会说话了。”

我：“你调教得好。”

第四夜：我困到不行，她偷偷给我盖外套

凌晨两点。

我写着写着，终于扛不住了，趴在桌上睡着了。

醒来时，感觉肩膀上多了点什么。

是小璇的外套。

她坐在我旁边，电脑屏幕照着她的脸。

看到我醒，她伸手摸摸我的头：

“睡一下嘛，你已经快成内存泄漏的线程了。”

“那你呢？”

她笑了一下：

“我这点小活不累呀，而且……你在旁边，我就不困。”

我心跳一下比一下快。

那一刻我特别想抱住她，但办公室里还有别人，于是我只是轻轻碰了碰她的手背。

那感觉比拥抱还暖。

第五夜：终于上线了，我们像打完最终 boss 的情侣

凌晨三点半。

活动上线。

顺哥喊着：“刷新！看看！有没有问题！”

我盯着线上日志，满屏 200，成功。

前端喊：“渲染正常！”

UI 小姐姐喊：“动效也没抖！”

全组瞬间沸腾。

即使是夜里三点，我们都像在踢世界杯一样激动。

小璇突然跳到我旁边，小声说：

“我们做到了耶！”

我看着她，忍不住笑出声：

“是啊，我们一起写出来的 618。”

她抬起头，眨着眼：

“那以后每一次大促，都有我和你，好不好？”

我没犹豫：

“必须有。”

她突然把额头靠在我肩上，轻轻说：

“有你在，我觉得……加班也变甜了。”

那天回家的路上，我突然明白了一件事

原来恋爱不是要多少浪漫、多少仪式。

有时候……

就是两个人
在凌晨三点的办公室里
互相靠着
一起写代码
一起扛压力
然后一起回家。

那种“你在我就在”的踏实感——
比情话更治愈，比礼物更贵。

我突然想：

这大概就是程序员最真实的浪漫。
