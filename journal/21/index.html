第二十一章：程序员的第一次“甜蜜危机”

阿雷1,857 字约 5 分钟

确认关系之后的那几天，我整个人像是刚从 debug 地狱爬出来，突然被系统塞给一份超高优先级 Buff——
谈恋爱。

每天上班写代码的时候，我都能感到心跳像 CPU 被人偷偷超频了一样，稍微想到小璇，工作效率直接上涨 30%，领导都以为我最近喝了某种“激活系统内核”的药。

但爱情嘛，有甜就有酸。

而酸这个东西……
就在不经意的某天，突然就触发了。

那天早上我正写一个会员中心的接口，写到一半，前端小姐姐红姐突然走过来：

“雷哥，你这里这个字段能不能再加个 tag？我前端这边展示需要用到。”

我一看需求，合理。于是跟着她去前端工位确认一下数据格式。

我俩很认真地盯着接口文档讨论：

“这个类型最好给个 number，string 我得再转一次。”
“那这个返回值我给你包一层 list？你们方便渲染。”

讨论得非常专业，非常纯洁，空气里只有技术的味道，毫无恋爱氛围。

我甚至脑子里全是 JSON、全是参数、全是响应结构。

完全没想到——
就是这么一个对接口的普通早晨
会引发我和小璇恋爱史上的第一次“冷战”。

我刚讨论到一半，余光突然看到一个熟悉的身影——
小璇。

她抱着平板，站在远处，看着我和前端小姐姐肩并肩盯着一个屏幕。

她的眼神从：

惊讶 → 微皱眉 → 无表情

整个过程不到三秒。

这表情……
我只在她看到设计稿被产品那边乱改时见过！

完了。
某种熟悉的危机感从脚底板窜上来。

我急忙喊：

“小璇，你来找我吗？”

她淡淡地：“没事，你继续忙吧。”

那语气不像没事，
像是数据库主键重复以后说的那句：
“继续啊，看你能写出什么惊天动地的错误。”

然后她头也不回地走了。

红姐看了我一眼：“诶？她是不是有点不高兴？”

我心虚到想 ctrl+z 回到一分钟前：

“可能……可能吧……”

红姐笑得意味深长：“懂了，我这边搞定了，你快去追吧。”

我赶紧追上去。

“小璇！你怎么了？”

她没回头，只丢下一句：“没有。”

这哪个程序员听不出来？？
这不是“没有”。
这是女朋友版的：

error:情绪异常，请立即排查

我只好硬着头皮继续问：“你是不是在生气？”

她停下来，终于转过头：

“我哪敢生气呀，我只是觉得……你对那个前端姐姐挺上心嘛。”

这句话……
醋味浓得能把带鱼腌透。

我立刻跳起来解释：“没有！纯工作！真的纯到不能再纯了的那种纯！”

她撇嘴：“是哦，你跟她说话还笑得挺开心的。”

我心里委屈得不行：

我那不是开心，那是程序跑通了的欣慰啊！
那是看到 200 OK 的自然反应！
这能怪我吗！

她没再说话，直接回位置坐下。

从上午到下午，她只通过微信联系我一次：

“下午的图我发你了。”

就这七个字。

没有表情包。
没有语气词。
没有小尾巴。

冰冷得跟数据库冷备份一样。

我整个人都不对劲了。

写代码心不在焉，连变量都命名成：

xiaoxuan_is_angry = true;
how_to_make_UI_girlfriend_happy();

连小马哥都问我：

“你今天咋啦？写个 for 循环都能写出 while(1) 那感觉。”

我长叹一声：

“恋爱遇到 bug 了。”

小马哥：“那你 debug 啊。”

我：“问题是我不知道报错堆栈在哪！！！”

小马哥：“呵，你完了。”

她一个人站在大厦下吹晚风，那画面安静得像一张没上色的 UI 稿。

我慢慢走过去：

“小璇，我们聊聊？”

她没说话。

于是我站得更近了一点。

低声说：

“你吃醋了，对吗？”

她还是不说话，但耳朵偷偷红了。

这小反应，比她说 100 句都更真实。

我轻轻抓住她的手：

“我喜欢你，这件事跟接口对接没有任何关系。”

她动了一下，但没抽开。

我继续认真地说：

“你是我女朋友。
你是我看到都会心跳加速的人。
我对别人不会那样笑的。
我笑，是因为接口跑通了，我不是对她笑的。”

她忍了半天，终于小声反问：

“那……你怎么对我笑？”

我低头贴着她的额头：

“对你……是控制不住的那种。”

她终于破功，小脸红得像被前端调成了 #FF4D4F。

下一秒，她轻轻地靠到我胸口：

“那你以后……不要忽略我……”

我几乎被她这句话融化当场：

“我一辈子都不会。”

她抬头看我：“那你现在要怎么补偿我？”

我：“请你吃晚饭？”

她摇头。

我：“要我背你回家？”

她又摇头。

我：“那……亲亲？”

她别过脸，但嘴角偷偷上扬：

“……也不是不可以。”

我靠，她这句话直接让我血压飙满。

然后她踮起脚，轻轻亲了一下我脸颊。

软软的、暖暖的，像爱情的 loading 条突然进度 100%。

我整个人直接差点死机。

她看着我笑：“这次原谅你了。”

我心想：“恋爱的bug可比程序的bug难解决多了😂！”

她笑得弯了腰：“好啦，我们吃饭去吧。”

她牵着我的手，十指相扣。

那一刻，我突然懂了：

爱不是没有误会，而是遇到误会时，两个人都愿意站到同一个方向一起解决它。
