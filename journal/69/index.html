约好认真聊的那个晚上，我下班以后没绕路。

买饭，回家，洗澡，把电脑里开着的几个工作窗口关掉。我甚至提前把手机充满了电，像要参加一场不能中途掉线的重要面试。

小璇比约好的时间晚了七分钟。

她接通视频先说抱歉，刚才跟家里通了电话。

我本来准备好的开场白，一下用不上了。

“又说武汉的事了？”

她点头。

屏幕里，她把耳机线从衣领旁边抽出来，调整了两下才坐好。脸上没有特别激烈的情绪，只是累。

那种表情我已经开始熟悉，却不喜欢自己熟悉它。

这一次，她跟父母讲得比以前具体。

武汉的工作机会，住处大致怎么找，过去以后不是完全没有朋友，真要遇到事情能找谁帮忙。

这些资料我们一起看过。我给她发过几个设计岗位，只发我认真看过要求的，没有把所有搜到的链接一股脑扔过去，假装事情已经很好办。

她也自己查过。

有些岗位方向不合适，有些待遇要再谈，但不是完全没有选择。真正卡着的，仍然是家里对距离的顾虑。

“他们说，工作哪里都有，为什么一定要去那么远。”她说。

我问她怎么回答。

“说武汉不是我临时起意。我想过，也了解过。不是随便找张票就走。”

她停了一下，又说：“可他们听来听去，最后还是担心，离得远以后，有事怎么办。”

我差点接一句，留在深圳也不可能所有事情都有人马上帮忙。

这话到了嘴边，我又觉得没用。

她不是没想过。她已经在一通电话里解释了很久，我不能让她换个对象再证明一遍。

“那你现在怎么想？”我问。

她看着我，过了好一会儿才说：“我还是想和你在一个地方。但我也没办法当作他们的担心不存在，直接把新工作辞了走。”

我点头。

她接着说：“最后留下是我做的决定，我知道。不是他们一句话，我就一点自己的想法都没有。只是我现在真的没想出一个大家都能接受的办法。”

这句话让我没法把问题简单地放在她父母身上。

他们是主要的阻力，但承受这份阻力的是她，做选择的也是她。隔着屏幕告诉她勇敢一点，比她真正收拾东西离开，容易太多。

她还提起自己做过的一件小事。

前阵子看武汉岗位时，她把其中一个方向合适的职位存下来，晚上重新整理了作品。没有立即投，是想先确认如果真走到这一步，自己拿得出什么。

她把屏幕转过来给我看，文件里已经分好了几个项目，连原来没时间补的过程说明也补了一点。

我看到文件修改日期，才知道这不是她今晚为了证明自己努力过，临时翻出来的东西。

“怎么没告诉我？”我问。

“还没定啊。”

她答得很自然，过了一会儿又说，怕我看见就以为已经快谈好了，最后家里还是不同意，让我再失望一次。

我想了想，告诉她其实可以说，不需要等到有结果。

她看着我，说你也一样。

我一下懂了。

我们都不愿意拿没做成的事去打扰对方，都想等一切更明确了，再带着一个像样的进展出现。可没结果的那段时间，在另一个人眼里就很容易变成什么也没做。

她问我最近看机会，是不是也怕一说她就开始期待。

我点头，承认有这个顾虑。

“期待本来就会有。”她说，“但你不说，我也会想。只是不知道你在想什么。”

我摸了摸桌上那张纸，把准备解释工作的几句话往后放了放，先告诉她自己现在最怕什么。

不是她催，也不是她不理解，是我怕承认想回来以后，却依然找不到。

这段话讲得不顺，几次停下来。她没有替我接，也没有把它立刻变成一句别担心。

轮到说具体安排时，我把这段时间看的深圳岗位打开。

收藏夹里有一些，真正投出去的却不多。

小璇看了一会儿，问：“你现在是想找，还是先看看？”

我下意识说在找。

话说完，又觉得不够诚实。

“大部分还是先看看。”

她没有立刻接话。

我把年初那几个月的感受讲出来。不是重复说 Java 多卷，也不是证明深圳没有任何工作，而是告诉她，我现在一想到辞掉眼前这份，再去等那些没有下文的消息，会很慌。

“我知道自己不能一直停在那时候。”我说，“可现在这份工资每个月按时来，活也能做，陈工他们对我不差。我真怕自己一松手，又回到那个状态。”

她听完说：“我没有让你先辞职。”

“我知道。”

“你是不是把回深圳，和裸辞以后一直找不到，放在一起了？”

我盯着她，半天没说话。

有一部分确实是这样。

她问的是能不能开始认真找，我脑子里却已经跑到了余额不断减少的出租屋，跑到午后等一通不会来的电话。

她每提一次，我就先为最坏的结果做防御。久而久之，她好像也不太敢提了。

“那我按在职找的方式来。”我说，“先整理简历，找能聊的机会，工资和职责合适再决定。”

她点头，却没有像我想象中那样松下来。

“然后呢？”

“然后拿到合适的机会，再商量过去。”

“如果一直没有呢？”

我看着屏幕，没能回答。

这是一个残忍又合理的问题。她不是要求我保证明天找到工作，她只是想知道，我们要把这样的日子过到什么时候。

我拿出纸，把能想到的方案列出来。

我回深圳，她来武汉，继续异地一段时间。

每一行下面都有具体困难。

我去深圳，需要找到能接住生活的工作；她来武汉，需要解决父母对远行的担心，也得重新找合适的岗位；继续异地，可以保住各自现有的工作，却没有替我们解决见面少、共同生活缺席的问题。

写完以后，纸很满。

事情没有因此变少。

小璇看见我低头写，轻声问：“你在记什么？”

我举给她看。

她看了一会儿，说：“你看，我们每一条最后都写再等等。”

我低头，发现确实如此。

等机会，等说服，等这阵忙完。

我们没有故意敷衍彼此，却一直在用一种没有日期的方式，许诺一个有日期才能发生的未来。

我试着提了年底之前再集中看一轮机会，之后重新商量。她问年底如果没有进展，是不是又要等过年以后。

我没有说绝对不会。

我不想为了让今晚好过，给她一个到时候可能做不到的承诺。

可不承诺，也会让今晚难过。

那通电话中间，我们第一次说出了带刺的话。

我说：“你家里要是能再松一点，可能也不会这么难。”

话出口，视频那头安静了。

她的脸慢慢绷紧。

“所以是我没谈好？”

“我不是那个意思。”

“可我听起来就是这个意思。我一直在跟他们说，你知道的。”

我靠回椅背，闭了下眼睛。

我知道她说得对。刚才那句话，把我不知道怎么解决的烦躁，推到了她已经很难的地方。

“对不起。”我说，“我着急了，那句话不该那么讲。”

她没立刻说没关系。

我也没追着让她原谅。

过了一阵，她说：“我有时候也会想，你是不是已经觉得武汉挺好了，只有我还在问以后怎么办。”

这句话戳得我也有点疼。

“我没这么想。”

“我知道你会想我。可是问起安排，你总说再稳定一点。现在已经稳定了一些，后面还有下一件事。”

我想起转正，想起演示，想起我一次次把收藏的岗位留到周末再看。

那些理由都是真的。

但她看见的日历，也是真的。

我们最后没有争谁更委屈。话说到这里，再把每一次错过拿出来计数，只会让对方越来越像一个需要举证的当事人。

她起身去倒水，我留在屏幕前，听见她那边水壶碰到杯子的声音。

以前同住的时候，这个停顿里我可以走过去，可以站在她旁边，可以接过杯子，哪怕暂时不说话。

现在我只能等她回到镜头里。

接下来两周，我确实开始认真整理简历。

武汉这半年的工作不能只写“负责订货模块”。我把做过的事情、承担过的判断和修过的错误分开梳理，挑能说明问题的部分，重新写成别人看得懂的经历。

我先把岗位要求分了一遍，不再看见 Java 就投。

有的技术方向离我太远，有的职责写得很泛，问了几句仍然说不清要做什么。也有两家确实值得继续聊，我认真准备了过去几段经历，找下班后的时间沟通。

其中一次，对方临时把电话提前到下午，我没有偷偷把武汉这边的会推掉去接，而是解释自己在职，重新约了时间。

重新约完，心里很急，怕就因为这一点错过。

可我不想一边说害怕失去稳定工作，一边先把现在的工作做坏。

那天晚上，我把这件事告诉小璇，她说这样安排挺好，接着跟我讲了她白天收到的一份反馈。

我们难得没有把话题一直停在城市上。她讲同事在会上误解了一个页面，我问后来有没有说明白，她说说清楚了，但过程有点累。

我说最近我们好像什么都要解释。

她笑了一下，说是，连下楼拿个快递，都要跟老板解释自己没有准备提前下班。

我也笑了。

那阵笑让我觉得，也许我们还有很多能一起过的东西，不应该只盯着最难的那一项。

可到了电话结束，我想问下一次什么时候见，话还是停了一下。

我们都知道，不谈那个问题的时候，可以相处得很好。可它并不会因为今晚没提，就自己往前走。

投出去以后，有人回复，也有人不回复。

一次电话沟通，对方问为什么来武汉不到一年又想回深圳。我说生活安排和长期发展都在考虑，没有拿感情做一套能获得额外同情的说辞。

聊完没有立刻得到下一轮通知。

我把情况如实告诉小璇，她说好，慢慢来，不要太急。

这句话明明很体贴，我听着却有一点难受。

她已经开始反过来照顾我找工作的焦虑，而我们原本讨论的是两个人怎么结束异地。

她也继续看武汉的岗位，还给我看过一个自己觉得方向不错的职位。我们聊了工作内容，没有把“有职位”直接当成“父母已经放心”。

事情在动。

只是动得很慢，慢到每一次沟通都需要额外用力，才能不让希望掉下去。

十一月快到的时候，有天晚上她发来一张街边的照片，说那家我们常买东西的小店换了招牌。

我回了一句这么快，又顺手问她今天和家里聊了没有。

她过了几分钟才回复。

“今天没聊。我只是想让你看看那家店。”

我盯着这句话，手指停在键盘上。

不知道从什么时候开始，我们连分享一个很小的日常，都容易被拐回同一个尚未解决的问题。

我把原先准备打的解释删掉，重新问她店里东西还是原来那些吗。

她回是，老板也没换。

我说那下次还可以去。

消息发出以后，我们都没有立刻接下去。

窗外有车驶过，光从天花板扫了一下。我把那张写满方案的纸翻过来，放到笔记本下面。

第二天，她说想找个晚上再好好聊聊。

我回了好。

我没有再追着问父母今天是什么态度。她白天上班，晚上处理自己的生活，不可能每一天都继续同一场说服。

我也不希望自己投出去一份简历，第二天就被追问有没有结果。可轮到等她那边的消息，我还是不知不觉把等待变成了对她的要求。

想到这里，我把手机拿稳，重新看那张店门口的照片。招牌颜色换了，门边以前贴的小广告还在，我终于找到了一件可以和她正常聊的小事。
