第一章：绿皮火车与南山初体验

阿雷2,079 字约 5 分钟

2017年6月29日，在学校被公司校招后，我背着行李踏上了开往深圳的绿皮火车。 说实话，坐在这列比我的编译速度还慢的绿皮火车上，我心里想着：“难道这就是人生的第一课——耐心？” 列车摇摇晃晃，车厢里空气不流通，座位也硬得像后端的老式数据库。 我的思绪像模拟器那样崩溃，心里默念：未来我是否能写出一段无 Bug 的代码？

火车上，我和几个同校的校招同伴坐在一起，有几个男生，几个女生 大家聊着未来的工作和人生，小李此时一本正经地说：“阿雷，你是不是觉得工作就像我们现在坐的火车，慢得要死，但最终会到目的地？” 我笑了笑：“是的，我希望到达目的地后，不再有崩溃的 Bug。” 小张插话：“那如果你发现目的地不对，能不能 Ctrl+Z？” 我没回复，低头默默想：“我现在最想知道的，是能不能在公司食堂吃到比学校更难吃的饭。” 车厢里有人打呼噜，有人叹气，我偷偷拿出笔记本写下第一条“深圳生存法则”：

  1. 火车慢，但梦想不能慢
  2. 带好充电器，否则会被生活报错
  3. 保持幽默感，是程序员必备技能

​到了深圳，我和同事们一起被安排住进了一个三室两厅的出租屋。 十个人挤在一起，空气中弥漫着咖啡和快递盒的味道。 晚饭后，我们在客厅围着桌子坐下，讨论公司分配的第一个项目 我原以为自己会写 Java 后端，结果三个月的 Android 开发任务压了下来。 我心想：这是坑？还是命运的试炼？ 那天晚上，我们像打开的 Java 堆栈，错综复杂却又无法停止。 小李睡在我的旁边，或是常常半夜调试代码时打出键盘声，或是打鼾声，把我吵得无法入眠。

我记得我第一天上班的心情——既紧张又兴奋。 我的脑袋里反复回想着上周面试时老板说的那句话：“你们都很优秀，但只有最能抗 Bug 的人能留下。” 我心里想：好的，我就是那个可以抗 Bug 的人。

公司的办公室在南山南园枫叶大厦，离住处步行五分钟的路程。 五分钟对于我们这些程序员来说，不仅是通勤的时间，还是“再睡五分钟”的黄金时间。 每天早上，我都在内心暗暗为这五分钟通勤的幸福祈祷。毕竟，通勤时间越短，调试的时间就越长。 不过，真正让我头疼的并不是通勤，而是模拟器。

到达大厦后，我站在楼下看了看这座金光闪闪的写字楼，心里暗自忏悔：“我没有想象中那么强大，可能比 Bug 更怕公司的大楼。” 小李站在我旁边，看着这座大厦说：“如果这个大厦能和我的模拟器一样稳定就好了。” 我苦笑：“别说了，模拟器我还没搞定，先别说大楼。”

到了公司后，老板老刘带着我们走进办公室。“欢迎加入公司，阿雷，今天你负责熟悉环境。” 我点点头，试图表现得不慌不忙，心里却在暗暗祈祷：“希望今天的任务能简单点，不然我可能会写代码写到崩溃。”

我被安排到一个靠窗的座位，坐下来打开电脑，看到公司内部 Wiki 上的开发文档。 我默默翻了几页，发现文档里的代码标准简直完美得不像话。 我的内心一度崩溃：“这对我来说简直就是重构梦魇。”

小李坐在我旁边，看到我苦着脸，悄悄过来：“阿雷，今天是不是有点大压力？ 我刚才也有点慌，老板说的那些需求，好像是从前端到后端的所有可能都包括了。” 我深吸一口气：“嗯，今天的任务是把我的精神内存写满，Debug 完美开始。” 小张这时过来了：“兄弟，第一天就放松点，先调试一下模拟器，看看它能给你带来多少惊喜。”

就这样，我开始了我人生的第一天，结果，模拟器就给了我最大的“惊喜”——它完全不工作！ 我调试了半天，那个模拟器画面静止不动，仿佛在嘲笑我：“你以为我会给你点正经的东西？做正式开发的第一天，先给你点小崩溃！”

我苦笑着看着模拟器闪退，突然心里明白了： 这就是 Android 的魅力——它让你又爱又恨，像一场无休止的 Debug 挑战。 小张见我一脸沮丧，拍拍我肩膀：“兄弟，你这是被模拟器压倒了。” 我回答：“不，它才是我调试人生的导师。”

中午我们去公司食堂吃饭，大家围坐一桌。 我低头看着餐盘里的一碗素菜，心里暗想：希望这个饭比我的代码编写顺利。 小张坐在我旁边，一边吃饭一边说：“阿雷，今天你第一天上班，肯定是想做个完美的第一印象吧？” 我点点头：“是的，但我现在只想让模拟器不崩溃。” 小李忍不住笑：“兄弟，你不怕一开始就做个 Bug 吗？” 我：“怕，但程序员的生活就是从 Bug 到 Bug，再到 Bug。”

就这样，我的一天开始了，又结束了。 虽然模拟器崩溃、任务压力大，但大家的笑声让我意识到， 在这里，每个人的 Bug 都是生活的一部分，能笑对 Bug，就是最好的程序员。

下班前，老板给我们开了个小会，讲了接下来的工作安排：“你们的第一个任务，是熟悉代码，优化功能。 如果遇到问题，不要怕，勇敢去 Debug。” 我在心里默默祈祷：“希望我的 Bug 比老板的笑话好调试。” 小李拍了拍我的肩膀：“放心，后端开发的你，调试模拟器应该没问题。” 我笑着点头：“只要模拟器不放我鸽子，应该可以。”

晚上回到住处，我们继续围坐一起吃泡面，讨论着第一天的工作。 小张咬着泡面，笑道：“兄弟，今天怎么样？模拟器有没有给你点惊喜？” 我抬头看了看大家，苦笑：“模拟器给了我惊吓，接下来给我点时间，我会让它给我惊喜。” 小李嘲笑：“你是不是想学会和模拟器谈恋爱？” 我：“如果模拟器能和我约会，我就可以死而无憾了。”
