第二章：通宵加班与凌晨五点的太阳

刚上班没两天，我们的项目团队来了一个大人物：林哥。 林哥是老板的同乡，也是那种走路都自带“我很忙但我很稳”的气场的人物。他第一天来，就站在办公室正中央，腰杆挺得像写得很完美的代码缩进，扫视我们一圈，笑着说：

“兄弟们，以后项目跟着我混！我带你们飞。”

我当场就知道：我可能不会飞，但一定会秃。

林哥年约三十，短发，皮肤黝黑，一股子“我调过的 bug 比你吃的泡面还多”的社会气息。他讲话永远斩钉截铁，仿佛每个句子都带着断言式注解。

他第一句话就是：

“最近项目急，你们准备好加班没？”

我们几个刚毕业的小伙子互相看了看，这种氛围只能点头，因为不点头显得我们不专业。 我心里想：“加班可以，只是希望不是 Android 加班，不然模拟器会杀了我。”

林哥继续说道：

“年轻人嘛，刚出来就是要吃苦。你们放心，苦不会白吃的，我请你们吃宵夜。”

听到“宵夜”两个字，我们这群刚毕业的穷程序员立刻振奋了十倍： 宵夜是加班界的 1UP 复活道具。

果不其然，项目上线临近，林哥第一天就带我们迎来—— 第一次通宵加班。

夜里 10 点，公司静悄悄，只有我们项目组灯火通明。 我坐在电脑前，面对一个怎么都不居中的按钮，内心开始动摇：

“为什么按钮不听话？难道它懂事了想跳槽？”

小张在旁边改接口改到绝望，突然抬头问我：

“阿雷，你觉得人生的意义是不是在这里？”

我揉了揉眉心：

“不是人生的意义，是人生的 bug。”

小李更夸张，他打开工位抽屉，里面居然塞满了泡面和五个能量饮料，像是准备参加战斗：“今晚谁先困谁就输。”

林哥则在旁边走来走去，不停盯我们写代码，偶尔还来一句：

“年轻人要拼啊！我以前连续通宵三天都没事！”

我默默看着他，心想： 哥，你是没事，我们会死啊……

凌晨一点，林哥拍拍手：

“兄弟们，走，吃宵夜！”

我们如同加班地狱里的小鸟突然飞出笼子，跟着林哥去了旁边的大排档。

林哥点菜豪爽极了，烧烤、牛肉、炒粉、卤味……整整一桌。 我们几个大学生瞬间感动得眼眶湿润：

“这就是职场大哥带小弟的感觉吗？”

我吃着烤串，心里默默想： 如果这顿饭能换我不通宵，我愿意加钱。

吃完宵夜回公司继续干活，机械地敲着代码，脑袋跟 NodeJS 的 event loop 一样永不阻塞。

直到某一刻，小张突然叫我：“阿雷，快看！天亮了！”

我抬头一看—— 卧槽，太阳真的出来了。

那是我人生第一次看见凌晨五点的太阳。 不是在操场上跑步，也不是在恋爱后送女朋友回寝室，而是在办公室…调试按钮居中。

那一刻，我有点恍惚：

“原来太阳每天都会升起，只是以前我都睡着错过了。”

小李揉着眼睛说：

“兄弟，我们这算是在迎接新生活吧？”

我叹口气：

“是的，新生活就是——继续加班。”

林哥拿着一杯早茶走进来，神清气爽，仿佛他不是通宵，是度假：

“兄弟们不错！今天我们继续冲！”

我们 collectively 心里喊： 哥，你确定你不是吸了能量石？

就在我们快被加班折磨成僵尸时，公司来了一位新的 UI 设计师。

是个女生。 好看。 非常好看。 那种“把加班值暴击减半”的好看。

她穿着简洁的衬衫，背个电脑包，笑着说：

“嗨，我叫小璇，以后 UI 设计我负责。”

我们这群小伙子瞬间精神恢复满血。

小张立刻坐直：“你好你好，我们做 Android 的！” 小李从椅子上弹起：“后端也在这！” 我默默点头：“我是…写按钮居中的……”

小璇笑着说：

“啊，你就是调按钮那个？加油哦！”

我当场差点泪目。 第一次有人对按钮居中这么鼓励。

而且她还很专业，开始和我们讨论界面设计的时候，林哥也罕见地放软了语气：

“小璇你说怎么就怎么，我们代码来适配。”

我心里默默记下： 原来我们项目需要的不是程序员，而是一个 UI 妹妹。

那天早上我们在阳光底下走出大厦，眼睛都被光照得睁不开。

我抬头看着南园枫叶大厦的玻璃外墙，心里有一种奇妙的情绪：

年轻的我们，第一次通宵加班，第一次看到凌晨五点的太阳，第一次在项目里有了 UI 妹妹……

虽然很累，但我突然发现：

原来成长不是一步步来的，而是被加班硬生生推出来的。

林哥说：“兄弟们，后面还有更难的项目，我们慢慢练。”

我默默想着：

只要每天加班后都有宵夜和 UI 妹妹，我…还能坚持一下下。
