旅游回来以后，我们把饭桌分成了两半。

小璇那边是作品集，我这边是简历。中间留一点位置放水杯，吃饭时再一起把电脑挪开。

这张桌子以前承担过临时加班、宵夜、周末懒得起身时的各种杂事，现在正式升级成两个失业人员的联合办公室。

一月，我开始认真投递。

最初觉得问题应该不大。

做过项目，带过人，处理过上线，也接过真实客户的问题。过去几年的经历摊开，总不至于完全找不到一份合适的 Java 工作。

我把简历发出去，顺手建了个表，记公司、岗位、联系时间和进展。

开始几天，那个表看起来很有希望。

几行新记录就能让人觉得自己正在往前走，状态里写着已投递，仿佛下一步只是等系统自动往下流转。

后来我才知道，有些状态不会自己动。

小璇比我快。

她整理完作品，投了几处方向合适的岗位，很快约到沟通。面试前一晚，她把准备讲的项目顺了一遍，让我听有没有哪里讲不清。

我坐在旁边，本来还想从技术角度提几个问题，听着听着，发现她把用户、方案和修改依据讲得比以前更完整了。

我说这版挺好，别只讲图长什么样，把为什么这么改说出来，对方会更容易理解。

她又练了一次，后面几句自然了些。

面试那天，她出门前问我鞋子配不配。我说配，接着想起她经常否决我的审美判断，又补了一句这次是认真看过的。

她笑着出门了。

几轮沟通下来，新工作定了。

她把确认消息给我看时，我正在修改简历里的一句话，抬头看了两遍，才反应过来。

“这么快？”

话说完，我怕她误会，立刻补一句：“好事啊，真的。”

她笑着点头，但也说还要去适应，新的产品和以前不同。

晚上我们煮了面，多加了两个蛋。她说不用这么隆重，我说新工作第一阶段的庆功宴，预算有限，请领导理解。

她让我别叫领导。

我是真替她高兴。

那顿面吃完，还帮她把入职要带的材料重新核了一遍。我甚至已经开始想，等自己也找到工作，饭桌终于可以恢复正常用途。

我以为再一两周，应该差不多。

第一场让我觉得有希望的面试，聊了一个多小时。

对方问我怎样处理批量任务和结果，我讲到我们以前遇过一次状态已经成功、实际结果却没完整保存的问题，怎么把各层确认拆开，怎么补足边界。

他继续追问失败重试和重复回调，我也能回答。

走出公司，我站在电梯口给小璇发消息，说聊得还行，感觉有戏。

她回了个加油，让我先吃饭。

那天我还顺手查了从固戍过去的路线，想着如果真上班，是不是该早点出门。

三天以后，没有消息。

我问联系人，对方说内部还在评估。

又过几天，告诉我岗位安排有变化，暂时不继续。

我盯着这句话看了一会儿，没有问到底是不是自己哪里不合适。对方已经给了一个结果，我再追着猜，也猜不出完整情况。

第二次面试换了个方向。

前面问基础，后面问很多我平时不太会按背诵顺序讲出来的细节。我有的答得顺，有的停住，需要想一想。

出来以后，我认真把没讲好的地方补了，没有因为觉得对方问得死，就一概当成别人不会面试。

可当我花了一整晚准备，下一家公司又换一种问法时，还是忍不住烦躁。

真正做过的事，需要先在一轮轮问题里证明自己有资格讲。

我懂这个筛选过程为什么存在，也没法因此就不累。

那阵子我最直观的感觉，就是 Java 人太多了。

等面试时，前后几个人聊的方向差不多；招聘软件里一个岗位挂着，发出去的消息很久才有人看。对方手里有别的人在比，我知道自己也只是其中一份简历。

有时候不是哪一场明确失败，而是始终没有走到能落地的那一步。

聊完技术，还要等后面安排；谈过期望，还要等内部确认；说本周有消息，到了周末，又变成下周看看。

我把表里的状态改来改去，最后发现最常用的一项叫待反馈。

它越来越长，几乎能单独组成一个部门。

与此同时，小璇已经开始每天上班。

她早上起来洗漱，问我今天有没有安排。我说下午有一场，她就让我中午记得吃，别空着肚子去。

有时没有安排，我便说今天在家准备。

最开始我还会详细讲准备什么，后来回答越来越短。

她晚上回来，放下包，问今天怎么样。我明明知道她是关心，却越来越难把那些重复的状态再说一遍。

“还在等。”

“对方有没有说什么时候？”

“说了也不一定。”

我语气有一次不太好，她看着我，停了几秒。

“我没有催你。”

我立刻知道自己把烦躁给错了人。

“对不起，我知道。”

她把买回来的东西放进冰箱，过了一会儿才过来坐下。

我重新把那天的事说清楚，也问了她新公司的情况。她讲了一段，我才发现她最近也在适应很多事，不是进了一家公司，后面就都自动顺了。

那晚我们约好，想问可以问，暂时不想讲也直接说，不要用一个很冲的回答让对方猜是不是做错了什么。

约定以后，我做得并不总是好，但至少知道该回头道歉，不能把失业当成对家里人发脾气的理由。

春节前，招聘那边更安静了。

有些沟通明确推到节后，有些干脆没再约。我们按原来决定留在深圳，给家里打电话拜年，没有临时买票回去。

我妈在镜头那头让我看看家里做的菜，问在外面准备吃什么。

我把我们桌上的东西拍给她，说也有鱼，也有肉，放心。

她看完说还行，又问找工作顺不顺。

我说节前都慢一点，年后接着找。

这句是真的，却也替我省掉了很多不好意思讲的部分。

视频结束，小璇坐在旁边问是不是想家。

我说有一点。

她没说那当初为什么不回去，只把筷子递给我，让我先吃，菜再放就凉。

那几天我们过得很简单。

做点饭，出门买点东西，沿附近的路走一走。她休息，我也暂时不用隔十分钟检查有没有新的面试通知。

有天我们整理旅行照片，看到她捧着热饮那张，她说那杯难喝的东西终于拥有了超出价格的存在感。

我笑着把照片存好。

然后不合时宜地想，等年后就好了。

这句话像一个可以暂时把焦虑放进去的盒子。我把它合上，跟她一起吃完了那顿饭。

年后，人陆续回来，机会确实比节前多了一些。

结果却没有立刻跟着来。

我扩大了范围，也调整过期望，只要职责合理、收入能接住生活，都愿意聊。并不是手里握着几份录用，只等最漂亮的那一份。

事实上，一份能签下来的都没有。

有次去面试，我提前到了一会儿，在楼下找地方坐。

旁边一个人也拿着文件袋，接电话时说自己来面 Java。挂掉以后，我们互相看了一眼，笑了笑，没有继续问对方准备了什么。

等进会议室，发现对方的问题单和我前几天准备的方向正好错开。我尽量把会的讲清楚，不会的承认，出来以后把没答好的几项记在手机里。

下楼时，下起了小雨。

我没带伞，站在门口等。手机里小璇问结束没有，我说结束了，先避会儿雨。她回了一句别淋着，我看着这几个字，忽然有点想立刻回家。

可回去的路也要时间。我站在门口，把下一个岗位的信息重新看了一遍，心里盘算如果时间合适，还可以把两场安排在同一天，少跑一趟。

这种盘算越来越熟练。

熟练到我能记住哪栋楼的入口不好找、哪条路换乘方便，却仍然没有一张属于下一份工作的门禁卡。

那天下午雨停，我去吃了碗面，没急着回去。吃完拍下店门口的招牌，想着哪天跟她一起过来。

我还没有完全失去期待，只是期待已经从某家公司会不会录用，缩成了一顿以后也许能一起吃的饭。

回家以后我把那几项没讲好的知识补完，整理到一页纸上。第二天接着投，没有因为难受就宣布自己再也不找了。

二月底，我又经历了一次多轮沟通。对方问得细，我也认真准备，最后说还要对比其他候选人。

等到三月，收到的结果是这次没有通过。

没有什么能拿来证明自己受了冤枉的戏剧性原因。就是在一场竞争里，对方选了别人。

我坐在出租屋里，把那一行状态改成已结束。

窗外晾着的衣服在动，楼下有人送快递，小璇还有两个小时下班。我看了眼时间，忽然不知道剩下这两个小时应该做什么。

资料不是没有可看的，岗位也还可以继续找。

但人不是按下刷新，就能把上一轮失望清空。

我靠着椅背坐了很久，最后起来把饭煮上。至少她回来能吃，不用在公司忙一天以后，再陪我一起面对一个空厨房。

那晚她看见饭，先夸了一句，接着注意到我没什么精神。

我把结果告诉她。

她说可惜，又问要不要一起看看简历里的表达，哪部分可能让人看不出做过什么。

我们确实改了一遍。

我把原来写得很泛的负责、参与，换成具体做过的判断和结果。她帮我删掉重复的句子，没有把我包装成一个什么都会的人。

改完已经晚了。

我看着她打哈欠，心里很不是滋味，说你明天还上班，先睡。

她说好，又提醒我别通宵看岗位，凌晨也不一定有人突然批量回复。

我答应了，过了一会儿却还是拿起手机。

我那时候最怕的，已经不只是没有工作。

是越来越习惯等待，等得连一天到底做成了什么都说不清楚。

三月里，我们又坐下来算过一次钱。

房租和生活费继续分担，哪一项暂时怎么付，讲清楚。小璇有了收入，不等于默认由她承担所有费用；我手里还有的钱，也不能因为自尊就装作永远不会用完。

她问我有没有考虑深圳之外的机会。

我说想过武汉。

说完才发现，这个地名以前更多存在于想家时，第一次真正作为下一份工作的地点摆到桌上。

她没立刻说好，也没立刻反对，只问那边有没有具体岗位。

我说还没有正式聊过。

她点头，说先了解，光在脑子里想，也不知道到底合不合适。

那天晚上，我又看到老清分享的一条招聘信息，他们公司在找 Java。

我把介绍从头看完，手机拿起来又放下。

我们平时也聊天，但突然开口问工作，总觉得像把关系换成了一件需要对方处理的事。我怕他为难，又怕自己故作轻松，最后错过一个真有可能的机会。

快睡前，我还是发了消息。

“你们那边最近真缺人吗？我想具体了解一下，不合适也没事。”

发完我觉得后半句有点多余，却没撤回。

第二天，老清打来电话。

“缺，岗位是真的。你把最新简历发我，愿意回武汉的话，可以先跟我们负责人聊。”

我握着手机，听他把公司做什么、现在为什么需要人讲了一遍。

他没有说包进，也没有用一句回来就行糊弄我。

就是一个明确的岗位，一个可以继续往下聊的人。

电话挂掉以后，我打开那份刚改好的简历，检查了一次文件名，发给他。

屏幕上依然没有录用通知。

但那张停了很久的表，终于多了一行和以前不太一样的记录。
