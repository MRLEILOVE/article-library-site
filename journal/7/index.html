第七章：核心开发的光环与生日的奇迹

阿雷1,267 字约 3 分钟

转正后的日子像加了润滑油的 IDE，一切都顺滑得有点不真实。就在我以为生活会继续平平稳稳地编译下去时，老板突然在全员群里甩出一句：

“大家下午三点全部到会议室，有重要项目要宣布。”

这话一出，我们公司立刻炸开了锅。平时从不看群消息的前端老王都忍不住冒了个泡：“是不是要涨工资？”
结果被大家集体嘲笑：“醒醒，这公司没你想的那么离谱。”

下午三点。会议室挤满了人。老板拍着桌子，脸上是久违的豪气：

“兄弟们，我给你们搞来了个大项目！叫‘华人行车行’，买车分润的！未来十万用户起步！公司未来就靠它了！”

老板说话斩钉截铁，甚至还有点上战场前的热血感。我们也跟着兴奋起来，仿佛下一秒就能让公司上市一样。

我心里默默激动：
终于轮到我施展拳脚的时候了！

老板一念激情还没过去，林哥就马上开始安排项目组。
然后，我听见了改变我“程序员尊严值”的一句话：

“后端核心开发——小雷！”

我当场差点从椅子上跳起来。
虽然“核心开发”距离“架构师老大爷”还有一百个等级，但光是这个名头就足够我高兴一个礼拜。

毕竟上个项目我只差点把库删了，而这次能被委以重任，说明老板不仅勇敢，还很有……胆量。

上次项目我们是怎么加班的？
白天写 Bug，晚上改 Bug，凌晨制造新的 Bug。
每次加班搞到怀疑人生。

但这次，不知道是项目天生体质好，还是我们都长大了，这项目竟然可以——
准点下班。

大家每天 6 点准时关 IDE，像大型逃亡现场，一秒不愿多留。
我甚至怀疑老板是不是偷偷买彩票中奖了，心情太好所以不逼我们加班。

这次项目涉及的页面比较多，我不得不和 UI 妹妹频繁讨论页面样式、布局、交互逻辑。

UI 妹妹依旧是那种仙气飘飘、连调色板都比别人浪漫三分的人。
每次她拿着设计稿和我说：

“这里的按钮我想要一种‘年轻一点的希望感’，你懂吗？”

我一般都点头如捣蒜，假装自己听懂了。
虽然我对颜色的理解只有“能点”和“点不了”两种。

但她每次夸我一句“沟通起来还挺顺畅的”，我能开心半天。

我甚至怀疑，自己写代码突然变快了，就是因为她坐我隔壁时，我不想表现得像个废物。

正当项目顺风顺水进行的时候，我的生日悄悄来了。

本来想着低调点，毕竟成年人的生日通常是“给自己加鸡腿”的仪式。
结果我一醒来就发现群里炸了：

“生日快乐啊小雷！”
“红包来一个！”
“祝核心开发越来越核心！”

我那天收到了人生最多的红包，数额都不大，但每一个都暖到心里。
到公司之后，大家还一起给我唱了生日歌，甚至连老板也掺和进来了，跑调得像 SQL 语句里的中文注释。

UI 妹妹还送了我一只她手绘的小卡片，上面画着一个戴眼镜的小程序员，旁边用细细的字体写着：

“愿你的代码永远有意义。”

我差点感动到重启自己。

开发进行得顺畅，团队默契得像不需要站会一样。
我第一次深刻感受到——

原来程序员也可以快乐啊。

不用通宵、没什么狗血冲突、同事们善良、有 UI 妹妹、有生日惊喜、有认可、有成长。

我走在下班的路上，看着晚风吹着科技园的树叶，突然感慨——

居然有点喜欢上这种简单又充实的生活了。

希望未来的日子里，我们能一起搞更多离谱又有趣的项目，
也希望我能继续在这群可爱的人中成长，成为真正能扛起系统的开发者。
