第十九章：偶遇UI妹妹

那天上午，我刚把一个“完美复刻线上事故潜力”的 bug 写完。那种 bug，你一看就知道：

只要跑到生产环境，它能把整个系统打得妈都不认识。

写完之后我正准备测试，但看一眼电脑右下角的时间——11:50。

再盯着代码，我估计要把午饭看漏了。
作为一个在深圳拼命卷生卷死的程序员，我深知一个道理：

能吃上午饭就算赢了今天的第一局。

于是我赶紧伸了个把肩膀都拉响的懒腰，对着隔壁的小马哥说：

“小马哥，走啊，吃饭去。再晚点食堂又要排队排成 Redis 队尾了，队列一堆等待…稳定性要打分了。”

小马哥摸摸自己的肚子：“走起走起，我已经饿到能把这个键盘啃出花纹来了！”

我们俩腾腾腾地往楼下奔。
刚走到公司大厦门口，准备往餐厅方向前进的时候，我突然，余光捕捉到了 一个熟悉得不能再熟悉的背影。

长头发，鹅黄色小外套，走路带一点点轻快的小跳步。

我心脏直接咯噔一下。

我不会是出现了幻觉吧？
我最近写 bug 写多了都开始出现 UI 幻视了吗？

我停下来凝视了两秒钟，越看越觉得像。

她侧脸露出一点线条，我的 CPU 瞬间飙升至 99%。

完了，是她。

是——
UI 妹妹小璇！

第一家公司那个坐我隔壁的UI 妹妹，
那个喜欢用甜甜奶茶味护手霜的 UI 妹妹，
那个每次画图都喜欢放《告白气球》的 UI 妹妹！

我内心瞬间被 JVM 直接触发 Full GC，一阵清醒到发麻。

但这时小马哥还在我旁边兴致勃勃地说着：

“今天吃麻辣烫还是炒粉啊？我昨天吃太辣，上厕所都像火箭升空一样。”

我脑子里瞬间跑出一个 if-else：

if（现在继续跟小马哥去吃饭）
    缘分直接 404；
else
    立即分支跳转，触发命运热更新！

我必须选择后者！这是命运给我打的补丁包！！

我当场捂着肚子，皱着眉头，摆出一种“生产环境爆红”的痛苦表情：

“小马哥……不行……我突然肚子痛，痛得像线上 Redis 宕机一样……你，你先去吃，不要等我……快去！”

小马哥人好得一批，被我吓得一哆嗦：

“真的假的？你快去厕所！别在我旁边突然 core dump 啊！”

我差点感动得给他发个大红包：“放心！我马上处理！”

他一走，我立刻进入“潜行模式”，像黑客植入补丁一样轻手轻脚贴近目标。
确认环境安全，我出手了：

“喂，小璇？”

她明显吓了一跳，回头的那一瞬间——那表情太要命了。

惊讶、意外，还有一点点抑制不住的开心：

“雷……雷哥？？你怎么在这？？你是我幻觉不？？？”

我差点笑出声：“我也以为你是我 bug 里的 UI 组件呢。”

她瞪大眼睛：“你不是在龙华那边工作吗？你怎么突然跑这里来了？”

我努力装得稳如老狗：“我来这家公司上班啊。你呢？你怎么也在这？”

她撅了下嘴：“我离职啦，来这边做 UI，待遇不错。你怎么不提前跟我说啊？”

说完，她低声补刀：

“还有，你怎么这么久都不联系人家……我以为你把我忘了。”

我心脏当场短路，一下跳成 404 状态。

她这语气……
这语气不太对劲啊先生们。

我急忙解释：

“不是不联系，是……最近搬家、找工作、面试、改简历、被拒、面试、加班……太乱了。我怕给你添麻烦。”

心里却嘀咕： 完了，这话怎么越来越像哄女朋友了？

实际上真实理由更简单：

是因为我对她的感觉有点复杂，不太敢主动。

但显然，我这解释在她心里勉强过了单元测试。

她“哼”了一声：

“算啦，看在你今天这么巧遇到我的份上，就原谅你一点点。”

然后我们一起决定——去吃饭。

路上她说她最近找房子找不到合适的，我说我也一样被中介折磨。

我们去了一家小炒店，她点了她最喜欢的番茄牛腩，我点了个炒河粉。

坐下后，我们开始聊天，从工作聊到生活，从深圳聊到老家。

聊着聊着，她突然问：

“你现在是不是变瘦了点？是不是工作太累啦？”

我装淡定，其实心里都快绷不住了：

“可能是最近学习比较晚吧……”

她轻轻笑了一声：“我就知道你又在卷技术。你啊，就是个行走的 IDEA。”

我差点被炒河粉呛死。

然后她又补一句：

“不过你瘦了也挺好看的。”

我：“？？？？？？”

这句话我当时感觉像有人往我头上浇了一瓶 82 年的 Bug-Free 冷却液。

不过她这句话……
是不是带点关心？带点暧昧？带点“我注意你很久了”的味道？

我心里开始跑一个 while 循环：

while(小璇可能喜欢我){
    心跳++;
}

但无论我怎么 debug，结果都指向同一个分支：

她对我好像真的不太一样。

吃饭期间，她还会不经意看我两眼；
我说一句话，她就笑得很开心；
她甚至夹了一块番茄牛腩给我，嘴上还说：“这个好吃，你尝下。”

兄弟们。

这玩意不是普通信号，这是带参数的函数调用！

吃到最后，我忍不住开始推理：

她主动问我为什么不联系；
她主动关心我是不是瘦了；
语气里还带点小埋怨；
这是不是…有点苗头？

我心里暗暗想：

不对，得找个机会验证一下！
程序员不讲玄学，我们讲证据、讲数据！
我得写个“感情单元测试”来验证她到底是不是对我有意思！
