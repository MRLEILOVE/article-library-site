Redis 命令行客户端

阿雷整理学习笔记约 1 分钟

原笔记 2022-07-28 · 整理于 2026-10-05

使用 redis-cli 连接 Redis、指定数据库并验证连通性。

本地连接示例

bash
redis-cli -h 127.0.0.1 -p 6379 -n 0

进入客户端后可以执行 PING 检查连通性。示例只连接本机；需要认证时按服务的 ACL 配置操作，不要把实际密码写进共享笔记或命令历史。

参考：Redis CLI 官方说明。
